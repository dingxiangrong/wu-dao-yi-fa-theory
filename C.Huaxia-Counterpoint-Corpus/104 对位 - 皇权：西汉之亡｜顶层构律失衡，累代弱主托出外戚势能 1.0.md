# 104 对位 - 皇权：西汉之亡｜顶层规制失衡，累代弱主托出外戚权势 1.0

【正文】
汉武帝以推恩令碎化封国，地方藩王集团带来的集中冲击风险被化解。武帝晚年国力耗竭，颁轮台罪己诏转向内守，朝廷对地方的管控力度自然回落，豪强势力再度获得发展空间。豪强在乡里慢慢坐大，属于长期潜伏的底层矛盾，一点点消耗王朝根基，但本身并不具备直接颠覆中央朝廷的力量。

大一统王朝顶层，存在两套相互咬合的规制。一套是嫡长继承的硬性制度，皇位依照血缘次序传承，不考量继位者的才干、年龄；另一套是顶层制衡体系：皇权、外朝朝臣、外戚三方彼此牵制，预留缓冲空间，维持政局稳定。两套规制表面配合，内里却存有冲突：嫡传制度锁定了继承人的选择范围，无法择优而立，而制衡体系想要正常运转，本就要求君主拥有足够掌控力。一旦接连出现能力不足的君主，这套制衡体系就失去核心支点。

嫡传制度本身自带局限：继位者若是幼主、弱君，君主自身掌控力自然衰减。幼主无法亲自处理国政，体制只能依靠母族外戚代为掌权，外戚便承接皇权分出的权力，逐步壮大。武帝朝已埋下此隐患 —— 改造诸领域唯独未建立外戚约束制度，只能依赖君主个人压制。后世弱主频出，此短板被无限放大。
一个王朝，如果只出现一代幼主，尚有机会待君主成年之后收回权柄，制衡格局还有修复的机会。西汉末年特殊的症结，在于**王政君历经数朝，接连伴随多位幼主、弱君**。外戚势力并非骤然崛起，而是跨越好几代持续积累权势，不断侵夺朝臣与皇权的空间。顶层权力总量固定，外戚权势持续扩张，制衡的缓冲空间不断被挤占，矛盾层层堆积。

待到王莽之时，外戚集团积攒的权势已经笼罩整个朝堂，权势笼罩之后，改朝换代只是时间问题，王莽只是恰好站在权势最高的位置上。没有对等的力量能够约束抗衡。顶层制衡体系率先崩塌，皇权空转、外朝失语、外戚独大，三方牵制退化为一方碾压。地方豪强带来的底层矛盾，是王朝根基的短板，在上层崩溃之后顺势爆发，放大动荡，却并非西汉覆灭的根源。

王莽代汉之后，效仿古制推行改制，陷入同一个误区：只照搬古制的外在形式，却无法重建古制赖以运行的缓冲空间，新的制度先天难以承载体系内部积压的各类矛盾，大范围动荡随之加剧。

西汉灭亡，根源出在顶层：固守嫡长继承制，接连出现幼弱君主，再加上王政君这条贯穿数代的纽带，外戚权势代代叠加，和皇权形成无法逆转的力量失衡，高层矛盾最终彻底爆发。此篇对应总评所列第一类覆灭模式：中枢内部矛盾自溃型。
