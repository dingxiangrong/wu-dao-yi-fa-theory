# 07 对位 - 礼制：周公与周平王｜隙存构稳，隙满则碎 1.0

【正文】
周公推行分封建制。华夏封国外围交错分布四方夷狄部族，诸侯之间不直接接壤，构成一层外部缓冲层，留出向外拓土的外延出口。诸侯向外开拓，征伐拓展的目标指向四夷，冲突向外疏导，华夏诸侯之间不必直接挤压碰撞，这套分封体系保有弹性，得以安稳运行。

历经两百余年列国向外拓地扩张，夷狄缓冲地带被侵吞殆尽。待到周平王之时，各封国疆界互相接壤紧贴，向外拓展的出口封闭，体系内部应力上涨，张力爆发。

西周之时，王室权威尚存，诸侯之间极少发生吞并灭国之事。周平王东迁之后，王室威权衰落，旧有的约束失效。

郑国本为王室近支，郑武公护送周平王东迁洛邑，身居王室卿士，率先向外征伐拓土，先后攻灭郐国、东虢国，再兼并鄢、蔽、补、丹、依、弢、历、莘八邑，一举占据中原腹地。郑国率先灭国拓土，开启诸侯之间相互兼并的先例。

此后百年间，楚国持续在南方吞并众多小国，齐国也不断兼并周边邦土，兼并之风逐步蔓延。百余年后，晋献公在位，采用假途伐虢之计，借道虞国攻灭虢国，回师途中顺势吞并虞国。晋国接连吞灭周边邦国，国土急剧扩张。

诸侯疆界相互抵近挤压，攻伐兼并接连兴起。诸侯之间空隙填满，隙满则碎，周室建立的这套分封秩序，便进入持续削弱、一步步走向消亡的过程。

二者对照，道理清晰：
周公建制承隙，凭夷壤以纳张力；
平王东迁隙满，外途闭而内应力涨。

【诗评】
夷壤作外障，
拓土引争冲。
边荒蚕食尽，
内应力相攻。

【引申对照】
企业快速向外扩张的时候，内部矛盾相对缓和。一旦外部发展空间受限，没法向外拓展，大家就只能在内部争夺资源、分蛋糕，各个部门之间的矛盾随之加剧。
