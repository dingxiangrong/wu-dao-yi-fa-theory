# 03 对位 - 礼制：周公与曲沃代翼｜构由力凝，力失则构弛 V1.0

【正文】
周公以征伐之力，确立宗法名分的秩序根基；曲沃代翼一事，则见证这套秩序体系，维系力量衰减，约束规则逐步松动。

后世读史，多受《资治通鉴》叙事框架影响，以三家分晋作为天下秩序崩坏的开端。这个节点醒目、大势无可挽回，却已是漫长松弛链条的末端。宗法秩序第一道难以收回的裂口，早在曲沃代翼之时便已出现。

当年管叔、蔡叔勾结武庚作乱，东方扰动四起，新生的周王朝秩序濒临倾覆。周公亲领大军东征，以强力扫平叛乱，而后制礼作乐，划定尊卑、名分、宗法、分封的框架，不止载于简册条文，更落实为婚丧祭祀、朝聘往来的日常仪轨。礼法不是凭空的文字约定，是征伐征战所稳固形成的约束稳态。秩序依靠力量维系，若无惩戒制衡的实力，名分便无从落地。这套秩序初立之时，王室手握王畿、王师，有能力讨伐叛者、矫正僭越；动乱一出，即可强力压回，约束稳固。

与之相对，曲沃代翼，则是另一番局面。

晋昭侯于前 745 年，将叔父桓叔封于曲沃。桓叔、庄伯、武公三代，持续冲击翼城晋君的嫡长正统，形成跨世代的冲突。冲突初期，王室尚有余力，数次出兵干预，扶持翼城正统，试图压制僭越、稳固秩序约束。平王东迁（前770年）之后，王室辖地缩减，维系宗法秩序的实力底盘持续收缩，干预诸侯的力量逐步耗散。王室虽有心守住名分，却无法根除这场冲突。至前 678 年，曲沃武公攻灭晋侯缗，进献宝物。周僖王已无力出兵征讨，只能承认既成事实，册封曲沃武公为晋侯。

条文依旧，嫡长继承、诸侯不得相攻的规制未变，执行这套规则的实力已然不足。不是秩序先行失效，也非周僖王主动毁坏规制，维系秩序的实力先行衰减，约束缓缓松开，冲突得以持续发展。

曲沃代翼，是这套礼制秩序弛化的一个关键节点。此后僭越、征伐、兼并不断累积，约束持续松弛。多年之后的三家分晋，只是旧秩序难以挽回余地的终局快照。司马光选取三家分晋落笔，取大势已去的标志，不等于秩序松动自这一刻方才开始。

二者对照，道理清晰：
周公之时，实力足以支撑秩序，动乱可诛，名分可守；
曲沃代翼之时，秩序的形制未改，维系秩序的实力已然不足，无力遏止冲突，只能承认既成事实。
