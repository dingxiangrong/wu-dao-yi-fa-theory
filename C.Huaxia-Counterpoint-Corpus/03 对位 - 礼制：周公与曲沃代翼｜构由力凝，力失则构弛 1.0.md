# 03 对位 - 礼制：周公与曲沃代翼｜构由力凝，力失则构弛 V1.0

【正文】
周公以征伐之力，凝宗法名分之构；曲沃代翼一事，见证**同一大构之下**，维系之力衰减，锁存逐步滑脱。

后世读史，多受《资治通鉴》叙事框架影响，以三家分晋作为天下秩序崩坏的开端。这个节点醒目、大势无可挽回，却已是漫长松弛链条的末端。宗法秩序第一道难以收回的裂口，早在曲沃代翼之时便已出现。

当年管蔡勾结武庚作乱，东方扰动四起，尚未锁存固化的新生周构濒临倾覆。周公亲领大军东征，以强力扫平叛乱，而后制礼作乐，划定尊卑、名分、宗法、分封的框架，不止载于简册条文，更落实为婚丧祭祀、朝聘往来的日常仪轨。礼法不是凭空的文字约定，是征伐运力固化形成的约束稳态。构由力凝，若无惩戒制衡的运力，名分便无从落地。这套构初立之时，王室手握王畿、王师，有能力讨伐叛者、矫正僭越；扰动一出，即可强力压回，锁扣稳固。

与之相对，曲沃代翼，则是另一番局面。

晋昭侯于前 745 年，将叔父桓叔封于曲沃。桓叔、庄伯、武公三代，持续冲击翼城晋君的嫡长正统，形成跨世代的扰动。冲突初期，王室尚有余力，数次出兵干预，扶持翼城正统，试图压制僭越、锁紧构的锁扣。平王东迁之后，王室辖地缩减，维系宗法秩序的运力底盘持续收缩，干预诸侯的力量逐步耗散。王室虽有心守住名分，却无法根除这场扰动。至前 678 年，曲沃武公攻灭晋侯缗，进献宝物。周僖王已无运力出兵征讨，只能承认既成事实，册封曲沃武公为晋侯。

条文依旧，嫡长继承、诸侯不得相攻的规制未变，执行这套规则的运力已然不足。不是构先行失效，也非周僖王主动毁坏规制，维系构的运力先行衰减，锁扣缓缓松开，扰动得以站稳。

曲沃代翼，是这套礼制大构弛化的第一个关键节点。此后僭越、征伐、兼并不断累积，锁扣持续滑脱。多年之后的三家分晋，只是旧构彻底失去挽回余地的终局快照。司马光选取三家分晋落笔，取大势已去的标志，不等于秩序松动自这一刻方才开始。

二者对照，道理清晰：
周公之时，运力足以托构，扰动可诛，名分可守；
曲沃代翼之时，构的形制未改，维系构的运力已然不足，无力遏止扰动，只能承认既成事实。

【诗评】
礼立凭威固，
威消法自疏。
条文犹在简，
锁扣已难拘。

【引申对照】
一套制度框架搭建完成之后，人们容易误以为条文本身可以自动维持秩序。实则制度只是锁存而成的构，它需要持续的制衡运力校准、纠偏。主动毁规属于显性破坏，极易识别；锁扣松脱是隐性衰变，条文、仪式都还保留，表面秩序如常，唯独执行惩戒的运力持续衰减。当规则一次次被试探、突破而不能矫正，每一次默许，都是一次锁扣的松脱。等到外界普遍察觉规矩失效，松弛已经层层累积很久。这种无声的渐变，远比公然毁规更难防范。

很多组织的溃败，不是主事者主动废除章程，而是维护章程的执行力量慢慢耗散，无力督守边界，违规不断被默许，最后既定规则形同虚设。后人往往拿最后一次标志性事件当作崩坏起点，忽略前面漫长、逐步松扣的过程。

【点穴手评】
构借运力成型，亦靠运力守锁。周公以征伐运力完成礼制建构锁存；曲沃代翼之时，构的文本不变，守构运力持续流失，锁扣在反复冲刷之下逐步滑脱。立构是瞬时定向的运力投入，守构是长期不间断的运力补给。

【百晓生评】
本篇承接 #02 周公立构的时序链条，观测构成型之后的弛化路径。区分两类破坏：一类是主动释放运力破规（商纣）；一类是维系运力自然耗散、无力纠偏（曲沃代翼）。前者是主动拆构，后者是构自弛。构存力衰，名分悬空，是礼制体系走向溃散的底层机制。扰动在本体系中指对构锁存状态的持续冲击，定义统一遵从《A40 变构本体论社会动力学》。
