# 05 对位 - 礼制：管仲与商鞅｜身入为榫，身出构外 1.0

【正文】
管仲订立规制，自身嵌入体系，充当核心榫件；商鞅搭建制度链条，身为制度构建者，却不滞留于这套秩序之内。

齐桓公时期，管仲推出轨里连乡、官山海、诸侯会盟等一系列举措，轨里连乡（以户籍编组管控基层）需因地制宜调整、官山（盐铁官营）海涉及利益再分配、会盟更依赖个人斡旋。条文虽立，这套秩序却缺少闭环的考核、追责与更替机制。大量利益权衡、边界裁断、对外方略，有赖管仲持续研判斡旋。管仲不单拟定规则，他本身就是维系这套体系运转无可替代的关键节点。管仲离世，条文虽存，整套霸业秩序随即失去校准。数年后桓公去世，诸子争夺君位，内乱爆发，尸身久未入殓，齐国的局面前后判若两重天。

商鞅入秦，确立军功爵、县制、连坐、耕战考核一整套连贯法度。他是这套法度的创立者，却不充当体系内常驻枢纽。法度内置统一标准、官吏轮换、逐级核查的流程，官吏仅作为流程内可替换执行者，无权随意更改既定方向。商鞅身死，这套法度链条不受冲击，秦法仍代代推行，百余年间持续收拢民力、核定军功、征收赋税，历经数代君主积蓄国力，最终以此根基完成天下一统。

二者对照，道理清晰：
管仲立规，以身充作枢纽，人逝则秩序僵滞；
商鞅铸制，抽身于法度之外，人去而规制延续。

【诗评】
寄身成榫契，
人远机轴停。
环轨先自立，
存亡不系形。

【引申对照】
放到企业来看，两种情形对比很清晰。有些公司请来能力出众的核心负责人或是职业经理人，业务靠着他快速做起来。但一旦这个人离开，这块业务马上就难以为继，这就类似管仲的局面。

也有企业会聘用外部咨询机构，结合自身情况逐步搭建组织制度与文化。这套体系不依附任何单个的人，人员发生更替，组织依然能够持续运转，近似商鞅建立的秩序。

人才与制度二者并行，并非互相排斥。当然这套体系也不是永久不坏，一旦底层支撑的力量慢慢消耗殆尽，企业依旧会走向衰败，只是它的崩溃，不会随着单个核心人员的离开立刻发生。
