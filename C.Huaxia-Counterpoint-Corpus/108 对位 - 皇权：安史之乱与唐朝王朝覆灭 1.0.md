# 108 对位 - 皇权：安史之乱与唐朝王朝覆灭 1.0（微调定稿版）

【正文】
唐初皇权母构（母构，即王朝顶层秩序的根基构型），脱胎关陇贵族盟构体系。隋代覆亡证明，盟构构型之下，若无独立征伐积攒的实体运力，顶层支点无力压制高能勋贵子构，应力无法疏导，构体极易撕裂。李世民扫平群雄，以南北征伐战事，积累独属于皇权的全域自有运力，以此拆解旧盟构锁扣，重构三省六部垂直中枢体系。早年中枢实行群相制度，凡加同中书门下平章事头衔者即为宰相，常有数名宰相于政事堂集体议事，多方校验、彼此制衡，顶层决策具备多层校准机制。此时三层权力应力，全部纳入可控约束。中枢职能咬合有序；中央持有力道，管控边疆与州郡；均田制授予农民土地，稳住基层编户底盘，中层豪强向下压榨的应力维持在低阈值，体系保持稳态。

高宗、武后时期疆域持续拓展，边疆防务范围不断扩大。面对吐蕃、突厥持续的边境冲突，唐睿宗李旦二次在位，景云二年正式设立节度使。这一步是彻头彻尾的臭棋，直接开启边疆养蛊，主动埋下毁灭王朝的地雷：为应对漫长边防线，将边疆区域财赋、人事、驻军权力打包交付边疆长官，边疆子构自此获得集中权限，中枢对边地的管控锁扣从根源上松动。把兵权、财权、人事权打包交给边疆一方长官，等同于放蛊于边境，一旦地方势力扎根，中央很难再有效约束，这是体系走向溃散的第一道重大转折。

到玄宗李隆基时期，对外持续开拓，边防压力进一步放大。玄宗早年励精图治，牢牢把持顶层支点，维持体系稳态；天宝之后，玄宗心生懈怠，疏于理政，原有制度逐步变形，构成第二道重大转折。唐初群相共治的中枢构律，在此阶段被破坏。李林甫主政之时，长期把持相权，政事堂其余宰相形同虚设，群相制衡格局瓦解，中枢决策由一人主导，失去多人互相纠偏的约束。李林甫行政手腕强悍，但为保全个人权位，刻意推行重用蕃将、久镇边疆的策略，边疆节度使长期扎根属地，势力持续固化。李林甫有控局之才，却以私念改动体系制衡规则，放大边疆子构的力量。杨国忠接替之后，缺乏驾驭多方势力的远见与手腕，朝堂内部制衡彻底崩坏，朝堂与边疆之间的应力持续堆积，矛盾再无缓冲空间。天宝十四载，身兼三镇节度使的安禄山起兵叛乱，史思明接续其乱，史称安史之乱，这是中枢 — 地方应力蓄积多年的总喷发。八年战乱，黄河流域州县反复遭兵祸破坏，唐廷大量可调度的兵员、财赋运力耗散。战乱平定之后，朝廷军力不足以根除河北叛军余部，只能就地任命叛将为节度使，承认藩镇割据的既成事实。河朔三镇节度使世袭传承，辖区内赋税自留、兵马自行招募，中层地方势力完成不可逆解绑。原发溃决卡点，在于中枢对边疆子构的管控锁扣滑脱。

藩镇割据成型之后，体系第二层溃决自中枢内部启动。开元之后，中书门下体制逐步取代旧日三省分工，原本三省咬合的中枢构律发生断裂，中书省决策链路虚化，外朝制衡机制失效。安史之乱后，君主忌惮外朝宰相与藩镇勾连，又不信任朝外武将，转而重用身边宦官。皇帝将神策军这支禁军交给宦官统领，依托近侍宦官子构，执掌军政与禁军大权。自代宗朝李辅国凭借禁军拥立君主，开启宦官掌禁军干预废立的先例。玄宗朝高力士虽受宠信、参与机要，但不掌重兵，和这一性质有本质区别；到文宗、僖宗时期仇士良、田令孜掌权，宦官集团掌握禁军，完成对顶层支点的实质性置换，能够干预甚至废立君主。中枢自此丧失统筹全域、校准层级应力的核心能力，顶层支点本身发生破损，无法再自上而下约束中层与基层。

中枢职能断裂、藩镇割据并行，地方中层势力获得无约束的经济支配权。藩镇、地方豪强、地方官吏，持续将治理成本向下转嫁到底层编民。均田制在盛唐之后逐步瓦解，土地大量流转兼并，失去土地的农民沦为客户、逃户，脱离户籍管控，编户底盘持续萎缩。现存在册编户承担全部赋税徭役，赋税压力加倍转嫁，土地高度兼并，赋税徭役层层叠加，流民持续滋生。中层势力的重心，不在于向上对抗残破的中枢，而是持续向下透支底层生存底盘。地方对底层压榨的应力，逐年堆叠，承载力持续衰减。

底层生存底线击穿，大规模底层起义接连爆发。唐宣宗末年，浙东爆发裘甫起义，冲击东南财赋重地；咸通年间，戍边士兵在桂州发动庞勋起义，切断江淮漕运，动摇朝廷钱粮根基。乾符年间，王仙芝率先起兵，黄巢接续起事，队伍辗转大江南北，广明元年攻破长安，这也是唐代破坏力最强的底层起义。黄巢败亡之后，黄巢麾下大将朱温归降唐廷，被朝廷收编。朱温借讨伐秦宗权、时溥等割据势力之机，逐步吞并中原州县；沙陀李克用凭借平定黄巢的军功割据河东。此时唐廷自身已经无可用武力，只能依靠朱温这类降将、藩镇去制衡各方势力。朱温借朝廷名号持续扩张，掌控中原军政大权；中央彻底空心化，只保留名义上的名分；底层大起义击碎旧秩序，地方藩镇割据已成定局。这股自下而上的应力，与藩镇割据自外而内的撕裂效应叠加，双向冲击整个皇权巨构。顶层支点破损，中层子构割据，基层底盘崩塌，三层应力全线击穿阈值，盛唐母构就此溃散。

唐亡的原发链条，始于两大源头：其一为睿宗设立节度使，边疆养蛊，将财赋、人事、兵权打包交付边疆长官，埋下地方割据的根子；其二是玄宗晚年懈怠，放任中枢群相制衡制度变形，顶层校准锁扣失效。边疆与中枢两处锁扣相继滑脱，后续层层传导，放大体系缺陷；中层持续向下压榨，积蓄底层应力，构成次生放大链条。东汉的崩塌，起于中枢主动松开中层锁扣，由底层起义引爆全局。唐朝的复杂度更高：地方藩镇形成固化割据在先，中枢内部决策体系同步崩坏，两套损伤叠加，双向传导，最终击穿整个大一统构体。裘甫、庞勋起义是前期预警，黄巢大起义是决定性重击，但底层起义依然不是原发起点，却是压垮已经破损巨构的最后一击。天祐四年，朱温逼迫唐哀帝禅位，大唐正式灭亡，天下进入五代十国的分裂割据阶段。
