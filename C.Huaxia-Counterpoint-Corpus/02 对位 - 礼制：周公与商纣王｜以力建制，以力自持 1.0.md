# 02 对位 - 礼制：周公与商纣王｜以力建制，以力自持 1.0

【正文】

剥离世俗千年的道德褒贬，仅从国家运力、统治模式、文明建制范式审视：
殷商王朝，拥有上古时代顶级的军事体系与王朝强权，国力雄浑、征伐强悍。

但殷商受上古时空认知局限，存在根本性的时代盲区：**只会以力自持**。

王朝握有强大武力，四方方国叛乱、边疆异动，皆以武力镇压、强权平乱。用兵只能换来短期归顺，矛盾无法根除。动乱平复不久，乱象再度萌发。常年平乱、持续耗力，陷入「伤其十指、永无闭环」的循环。

殷商的历史缺陷，不在于力量不足，而在用力维度单一。它手握强权，只依靠武力压乱、消耗势能，不懂得凭借这份力量浇筑制度、搭建架构、固化秩序，最终落入循环。

周公摄政七年，据《尚书大传》载：一年戡乱，二年东征，三年践奄，四年建侯卫，五年营成周，六年制礼作乐，七年还政成王。
由这段史实，可以梳理出三件核心工作：

1. 戡乱东征，平定各地叛乱，掌控天下局势，取得统治运力。
2. 地缘布局，推行分封、设立侯卫藩屏、营建洛邑，稳固疆域底盘。
3. 建制，搭建国家权力体系，订立礼乐制度，固化天下统治秩序。

在周公的诸多贡献中，核心贡献是建制。他搭建起礼、乐二元制度体系，其影响分为两个层面：

1. 王朝层面：这套礼乐制度，支撑周王朝存续八百年。
2. 文明层面：这套建制体系，成为后世王朝立制的标准范式。

**礼，包含六大核心纲目：**

1. 义：界定天下秩序的道义本源，确立治理合法性。
2. 分：划定社会层级与君臣权责，明确秩序边界。
3. 时：规范祭祀、朝聘、政务推行的时序。
4. 位：确立朝堂位次、城邑规制、疆域管辖范围。
5. 器：制定礼器、车服、典章信物的等级标准。
6. 仪：统一朝野往来、祭祀庆典的言行规范。

从现代 5W1H 治理框架视角，对礼的这套上古范式做阐释：

1. 义（Why）：对应治理的目标初衷，明确立制目的，回答国家为何立制、要平息何种乱象、建立何种秩序。
2. 分（Who）：对应治理主体与对象，划分层级、权责，明确治理的执行者与约束对象。
3. 时（When）：对应时间体系，划定政务、典礼开展的周期与规则。
4. 位（Where）：对应空间体系，划定朝堂、地方、疆域的管辖边界。
5. 器（What）：对应落地载体，明确典章、等级、实体规范等治理内容。
6. 仪（How）：对应执行准则，规定公务、仪式的行事方式，保障制度落地。

礼依托这六维体系，形成硬性、可落地的规则框架。
乐与礼平行，承载价值形态与意识形态，用以引导人心，凝聚社会认同，降低礼制推行的阻力。

周代之后，王朝开国定典、盛世修礼、变法改制，多以这套二元范式为基础。
春秋礼崩乐坏之后，诸子百家争鸣，各成治世学说。各家只深耕单一治理维度，不能掌握完整的国家建制体系。如儒家承袭礼制表层仪轨与道义，没有触及周礼内核。
王朝长期沿用这套范式，诸子百家仅窥见局部，印证周公礼制范式的历史高度与文明价值。

【诗评】
强力空自耗，
无构难自持。
藩屏环京邑，
周礼铸华魂。
