# 109 对位 - 皇权：两宋之亡｜忘本：忘地缘之本 1.0

【正文】
一切上层权力构造，必以地缘疆域作为底层基底。疆域不能守，所有精巧的权力制衡、繁盛的经济积累、活跃的思想文化，都会失去承载根基，沦为悬空之构。这是皇权演化的根本构律。两宋立国，源自对五代军阀割据乱象的应激矫枉，却在制度设计之中放大取舍、遗忘立国之本，这是其覆亡的核心根源。

两宋，与秦汉隋唐晋诸统一王朝存在本质区分。前述王朝覆灭的原发动力，来自体系内部三层应力蓄积，锁扣滑脱，构体由内先行溃决。两宋不同。两宋内部，中枢、地方、基层三层应力，并未抵达全线击穿阈值。国内虽有民变起义，起事规模有限，不足以撼动皇权母构根基。皇族对于内部权力制衡，维持尚可；朝堂文士论辩往复，思想氛围相对开放；社会经济持续积累，物质底盘保持充盈。体系内部，不存在足以令其自行崩塌的原生溃点。

两宋的倾覆，原发冲击来自外部。自辽、金、西夏三面环伺，至蒙古铁骑南下，外部应力持续加码，靖康北迁、崖山终局，外部游牧强权作为高能外部子构，持续施加高强度军事外力，逐步把构体推向承载力上限。外力能够击穿，根源根植于立国之初的路径选择。唐末五代，武将手握重兵，割据相伐，天下动荡。宋自五代乱世之中立国，为根除武将军阀坐大的风险，便定下弃武重文的底层构律，主动限制武力，压缩武力自持的势能。这套设计，的确锁死地方武将子构割据作乱的隐患，朝堂内部权力平衡得以稳固，内部不再出现军阀撕裂国土的危机。但取舍的代价极为沉重：国家丢掉武力这个立国根基，也丢掉守护地缘疆域的自持能力。

西汉同样面对强大的外部游牧势力匈奴。西汉保有自持征伐运力，守住地缘底盘，依托国土纵深组织长期对抗，逐步缓释外部压力。两宋专注于打磨朝堂内部权力平衡博弈。文士之间争论辩难往复不休，党争往复，精力消耗于内耗博弈，无人聚焦武备整饬；经济、思想层面维持开放活跃，却忽略一条底线：所有内部博弈、繁华盛世，都建立在武力足以守护地缘疆域这个前提之上。一旦外部强敌的军事冲击到来，缺少自持武力捍卫疆土，再精巧的制衡、再繁荣的经济与思想成果，全部无从依托。

**两宋之亡，不是内部应力蓄积自溃，而是立国路径矫枉过正而忘本。**

内部权力平衡尚可维持，经济尚有活力，思想相对开放，唯独舍弃武力立国之本，遗忘地缘疆域才是权力的承载基底。内部结构性短板，叠加外部强大外力持续冲击，合力击穿皇权巨构。若无外部强敌这股外力，这套内部构律可以长期延续，不会自行走向溃散。武力为立国之根，地缘为权力之基；根一旦丢弃，所有繁华与制衡，皆成浮寄。

疆土为权基，
崇文弃甲戈。
繁华浮在上，
根失遇风蹉。
