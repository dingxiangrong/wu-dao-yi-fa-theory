# 105 对位 - 皇权：黄巾之变｜底层矛盾喷发，中枢自解中层之锁 1.0

【正文】
东汉承袭帝制嫡长传承的刚性规制。自第二位皇帝汉明帝之后，在位君主大多英年早逝，冲、质、桓、灵皆短祚。幼主临朝，君主自身掌控力先天不足，给了外戚、宦官轮番掌权的机会，顶层陷入往复厮杀的矛盾循环，不同于西汉外戚单向叠加权势，东汉是外戚与宦官交替掌权、互相倾轧。长年累月的顶层内耗，持续耗损朝廷管控力量，中枢逐步失能，失去监察、约束郡县中层豪强的能力。

管控约束失效，地方豪强开始野蛮生长。豪强凭借手中经济支配权，不断向下挤压，土地与财富资源逐步向豪强聚拢，底层民众失去赖以生存的资本，民不聊生。矛盾积蓄到临界点，黄巾起义爆发。

失能的中枢无力镇压这场大范围动乱，解锁了地方豪强发展武装力量的管控锁。黄巾主力虽很快被剿灭，战事虽平，但地方募兵已成既定事实，武装力量散落民间、依附豪强，再无收回之途。地方豪强的势力已经成型，最终形成地方割据。由此开启了长达数十年群雄逐鹿的割据时代，这也是三国前夜至关重要的历史阶段。

【诗评】
幼主损皇威，
中层暗蓄机。
下民遭迫蹙，
一乱撤重扉。
