# A45-E02.异化的基础教育类竞赛：目的迷失，自我矛盾

面向基础教育阶段的各类竞赛，包括奥数、计算机信息类赛事，首先必须叩问本源：举办一场基础教育阶段的竞赛，它的目的究竟是什么？

这个目的绕不开一个核心问题：竞赛考察的，到底是教学大纲以内的知识，还是大纲以外的知识？用的到底是什么纲？

正常逻辑应当非常清晰。既然面向对应年级的在校学生，那就必须使用该年级教育部颁布的教学大纲作为竞赛的约束之纲。竞赛应当是课内教育的延伸，考察学生基于已经学过的课内知识，所能展现出的逻辑、推演、思辨能力。它比拼的是同一套知识地基之上思维水平的高下，而不是比拼谁提前自学了还没教的内容。

如果一场竞赛，不能明确回答 “我遵循哪一个年级的教学大纲”，不能划清哪些知识允许使用、哪些知识禁止拿来得分，那这场竞赛从根源上就讲不清自己的目的。目的模糊，存在的正当性自然就消失了，这类竞赛本就应当被叫停。

可现实大量竞赛恰恰回避这个根本问题。没有锚定对应学段的官方教学大纲，考察边界随意游走，大量题目直接挪用更高学段的知识内核。给初二学生出题，却把高中数学的知识点改头换面放进去。这不是考验初二学生的思维，考的只是这个孩子有没有提前去学高中内容。

出现这类超纲命题，首先是专业无能，往深看，这种行为本身就是无耻的。无能，是没有本事在本年级已学知识的框架之内，设计出有思维深度、有区分度的好题，只好简单借用更高学段的知识点来制造难度；无耻，不在于特指哪一个出题者个人品行，而是就行为而论：明明清楚教学大纲划定的学段边界，明明看得见超纲带来的不公与拔苗助长的后果，却依然持续这么做。

很多参与命题、组织赛事的人，本身就身处教育体系之中，不少人就是教师、教研员，本应是教学规则的守护者。教育本是塑造下一代的灵魂工程，从业者身负为人师表的育人使命。当规则的守护者亲手突破学段边界，一再制造这类乱象，是对这份职业使命的背离，这样的现象，我认为是不可容忍的。

这种行为会带来一连串恶劣后果。其一，实实在在加重学生负担。为了竞赛拿到不错的结果，学生不得不脱离正常课堂进度，提前去啃还没有安排学习的高阶内容，挤占休息、运动、阅读的时间，减负的政策导向被直接消解。其二，造成大范围的拔苗助长。人的认知成长有客观节奏，教学大纲就是按照青少年认知规律编制而成。还没有到对应的成长阶段，强行灌输后续学段知识，学生大多只能死记套路，表面题目能做对，底层逻辑无法消化，换来短期抢跑得来的分数优势，伤害的是长期的学科思维。

这里就暴露出整套现象的自我矛盾。不是外人在拆台，是自己人在砸自己的地基。体系自己制定教学大纲，划定各年级知识边界与学习节奏；但体系内部操办的竞赛，在实践层面却与这套大纲的制度设计相互冲突。大纲写明初二不应接触高中知识，竞赛却把高中知识包装成考题筛选初二学生。一次次越纲命题，不断消解教学大纲的制度权威，基础教育正常的教学秩序，就这样被竞赛的指挥棒带偏。

于是竞赛彻底变味。它不再是给少数热爱学科的孩子切磋思维的平台，变成比拼课外补课、比拼抢跑速度的竞技场。孩子有没有天赋不重要，课外投入多少超前学习的时间，才决定竞赛成绩。很多本无兴趣的普通学生，被内卷裹挟，被迫卷入超前学习的洪流。

商业力量进一步放大这套弊端。没有刚性的学段大纲约束，培训机构依托竞赛输出超前知识点、二级结论与解题套路。竞赛变成课外培训的引流抓手。不参与课外补习，很难在赛事拿到可观成绩，内卷持续传导至普通家庭。

除开大纲缺位，训练导向同样跑偏。合规的竞赛训练，应当依托本年级知识，引导学生拆解、推导、建模。实际训练却绕开理解，直接灌输套路解法。学生记熟做题步骤，未必懂得背后原理。部分命题还留有蛮力枚举的通关路径，不需要深度思考也可以得分，久而久之养成回避本质思考的思维惰性。

我们并不全盘否定竞赛这种形式本身。只有同时满足几条硬性条件，竞赛才有保留的价值：严格锚定参赛年级对应的官方教学大纲；限定只能使用本学段课内知识；禁止超前超纲内容作为得分手段；不强迫学生课外加码，不给普通学生制造额外负担；立足于本学段的认知，挖掘逻辑与思考的深度。这样的竞赛，才可以用来甄别思维禀赋，服务课内教育。如果觉得现有大纲的深度不足，正确路径是参与正规教研，推动教学大纲迭代升级，而不是在竞赛里直接越纲行事。

竞赛想要回归正轨，第一要务就是立纲。纲不立，减负、纠偏、规范训练等所有设想都没有基准线，只能沦为空谈。参赛学生是什么年级，就严格执行该年级教育部颁布的教学大纲。超纲即犯规。出题人的功力体现在纲内挖深度，不是向外借知识点堆难度。剩下的，都是细则。

如若不然，任由大量目的模糊、肆意越纲的竞赛继续蔓延，只会持续制造内卷，助长拔苗助长，消耗大量学生的时间精力，只产出熟练的做题者，却很难培育真正独立思辨的头脑。
