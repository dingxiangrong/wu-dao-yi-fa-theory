# substack Notes 短笔记（适配发布，作为正文文章的引流钩子，风格同 A45 教育专题）

基础教育阶段的学科竞赛，最根本的问题，从来不是难度高低，而是**有没有立纲**。

竞赛面向哪个年级的学生，就应当以该学段官方教学大纲为边界。 真正高水平的命题，是在已学知识的地基之内，挖掘思辨、推演、建模的深度，考验思维本身。 而不是把高年级知识点改头换面拿来出题，变相比拼谁超前学得多、课外补习投入更多。

一旦竞赛脱离学段大纲约束，竞赛就不再是思维切磋的舞台，变成超前抢跑的内卷竞技场。 培训机构顺势把竞赛当成引流工具，拔苗助长随之扩散，持续挤压孩子运动、阅读与休息的时间。 学生练熟套路，却丢失底层思考的能力，最终产出大量刷题机器。

竞赛本身并非洪水猛兽。 底线只有一条：**纲内求深度，纲外不拿分。** 出题人的功力，在于向内深挖，而非向外借知识点堆砌难度。 纲不立，则一切规范、减负都是空谈。
