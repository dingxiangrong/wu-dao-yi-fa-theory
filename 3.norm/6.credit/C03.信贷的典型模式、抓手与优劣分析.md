# C03.信贷的典型模式、抓手与优劣分析

## 前言

信贷底层唯一核心原理：
所有信贷业务能够成立，根基只有一条：**锁定借款人的履约软肋**。

所谓软肋，就是一套刚性约束机制：
让借款人权衡之后，履约成本 ＜ 违约成本。

没有有效软肋，所有风控都是纸面评估，借款人主观违约时，资金方无有效追偿手段。

所有信贷模式的差异、优劣、风险等级，
本质就是：软肋类型不同、约束强度不同、风险载体不同、是否依托人性道德风险。相较于传统按照抵押、质押、保证、信用的担保方式分类，以**软肋约束强度**作为统一标尺，更能够穿透表象，揭示信贷风险的底层本质。

本文完整覆盖：对公全品类、供应链保理、政信城投授信、对私经营贷、按揭、信用卡、消费分期、抵押消费贷，为国内信贷底层结构拆解。

## 第一部分 对公信贷体系（法人主体）

### 1. 上市公司股权质押授信

**核心抓手**：可动态盯市的标准化金融资产、补仓机制

**原理**：
以企业持有的上市公司股权质押，银行实时盯市，股价下跌触发阈值即要求补仓，不补则启动处置。

**优点**：

1. 全市场实时公允定价，唯一具备动态风险止损能力的抵押品类。
2. 资产标准化、流动性远优于厂房、设备、土地。

**缺点**：

1. 强顺周期，大盘系统性下跌时股价断崖式跳水，补仓机制来不及反应。
2. 限售、司法冻结、诉讼会导致资产无法即时变现。
3. 适用范围极窄，仅头部上市主体可用。

### 2. 企业实物资产抵押（厂房、土地、设备）

**核心抓手**：不动产抵押登记、司法处置兜底

**核心底层悖论（全文最重要逻辑）**：
这类实物资产全部属于顺周期实物资产，账面估值极度虚高。抵押物的实际有效性，和它真正被需要的时刻呈逆相关：企业经营向好时，抵押物完全用不到；企业经营崩塌、需要依靠抵押物代偿的时候，行业下行，资产贬值、市场无人接盘。

由此得到更深层结论：绝大多数对公实物抵押贷，真正风控抓手并不是抵押物本身，而是**放款时点企业当下的经营状态**。一旦经营基本面发生逆转，抵押更多只具备心理威慑意义，这也是银行对公不良的结构性来源。

真实情况永远只有两种状态：

1. 企业经营好、能正常还款的时候：抵押物完全没用、根本用不上
2. 企业经营崩盘、真正还不上钱的时候：行业下行、资产贬值、无人接盘

所以：企业实物抵押，本质上等于形同虚设。

**优点**：
仅具备法律形式兜底，心理威慑作用。

**缺点**：

1. 估值一次性快照，无动态盯市，风险后置。
2. 工业资产流动性极差、处置极难、折价极高。
3. 一旦出险，单笔不良损失率 50%–100%，是银行最大坏账源头。
4. 大量资产产权瑕疵、集体土地、无证建筑，无法处置。

### 3. 央国企纯信用授信

**核心抓手**：主体行政声誉、国资考核、信用追责、持续经营资格

**原理**：
不靠抵押、不靠资产，依托国资体系信誉与制度约束授信。

**优点**：

1. 无抵押、大额可批、履约稳定性极强。
2. 几乎无主观逃债意愿。

**缺点**：

1. 无资产兜底，危机时仅靠行政约束。
2. 利率极低、利差极薄。
3. 集团互保、体系风险传染严重。
4. 无刚性兑付法律保障。

### 4. 大型民营集团主体授信

**核心抓手**：市场持续经营预期、规模信用、融资链条惯性

**优点**：
单笔规模大、投放快、适合集团统筹。

**缺点**：

1. 完全建立在 “持续经营预期” 之上，预期崩塌则抓手直接失效。
2. 账面资产多为土地、在建工程，顺周期虚高、变现极差。
3. 报表美化、借新还旧普遍，底层现金流难以穿透。
4. 爆雷即为集团系统性大额坏账，风险高度集中。

### 5. 政信 / 城投类授信（新增）

**核心抓手**：地方政府隐性信用背书、平台再融资滚续能力、政策博弈空间

**原理**：
既不依托实体抵押物，也不完全等同于市场化企业经营现金流，介于普通民营主体授信与正规央国企授信中间。它的履约软肋不是简单的借款人违约成本，同时绑定监管政策容忍度。违约往往不是客观上完全没有偿付能力，而是受政策窗口指导、财政统筹节奏约束。

**优点**：

1. 单笔规模大，存续期长；在政策稳定周期，整体履约意愿较强。
2. 不依赖单一项目现金流，依靠平台整体再融资接续。

**缺点**：

1. 约束抓手高度依赖政策环境，政策转向之后原有信用逻辑直接弱化。
2. 现金流与项目收益经常脱节，高度依靠外部滚续融资。
3. 债务边界模糊，隐性债务风险容易跨区域、跨平台传导。

### 6. 供应链金融 + 保理业务（最优结构对公业务）

**核心抓手**：核心大企业、国企、上市公司的刚性兑付信用

**核心本质**：
保理是银行所有对公业务里，风险结构最干净、最不依托人的业务。

> 边界条件：该结论建立在**贸易背景真实、确权完整有效**的前提之下。若供应商与核心企业串通虚构贸易，风险不再是中小企业的个体道德风险，而是直接等同于核心企业的违约风险。保理风险下限不等于零，等于核心主体违约概率；只是该概率远低于中小民营企业经营失败概率，因此结构依旧最优。

1. 完全不依托借款人（上游供应商）
不管小企业经营好坏、老板人品、道德风险、跑路与否，完全不影响回款。
2. 彻底剥离所有个人道德风险、经营风险、主观违约风险
3. 依托的是已经真实发生的贸易债权 + 核心大企业兑付能力
不是预判未来经营，是锁定确定应收。

**优点**：

1. 无个人道德风险、无经营者风险、无主观逃废债风险。
2. 贸易背景真实、资金闭环、用途锁定。
3. 风险极其稳定，是银行对公里最干净、最可控的资产类型。

**缺点（仅存风险，非人性风险）**：

1. 虚假贸易、虚构应收账款。
2. 核心大企业自身信用崩塌。
3. 买卖双方贸易纠纷导致抗辩拒付。
4. 确权瑕疵导致回款错位。

总结：保理不是零风险，但是零人性风险。 所有靠 “人” 的风险全部剔除，是信贷结构最优模型。

## 第二部分 对私信贷体系（个人 + 个体户）

### 1. 个体户线下小微经营贷

**抓手**：商圈声誉、本地圈子信用、线下软信息

**优点**：识别真实小微经营状态
**缺点**：极度依赖人力、道德风险高、不可规模化

### 2. 互联网平台经营贷（网商、微众）

**抓手**：经营收款通道、交易流水、生态约束

**优点**：数据动态监控、批量获客、软约束极强
**缺点**：依赖平台生态，可被换通道规避

### 3. 个人房产抵押经营贷

**抓手**：个人住宅不动产抵押

**特点**：
依然属于顺周期资产、估值时点虚高，但住宅流动性远强于工业资产。

## 第三部分 个人零售核心资产（银行压舱石）

### 1. 个人住房按揭贷款（国内银行历史至今最优资产）

**核心逻辑**：资产质量从未下降，只有业务增量萎缩。

> 补充时间维度监测：虽然历史不良率维持低位，但伴随新增按揭增速下行、存量大规模提前还款，银行按揭资产久期持续缩短，净息差被持续挤压；同时新增客群逐步由收入上升期刚需家庭，向置换、改善型客户迁移，部分客户杠杆抬升，家庭现金流缓冲边际变薄。资产整体质量没有降级，但资产韧性出现边际收窄，属于重要的中长期观测指标。

**核心优点（最顶级信贷资产特征）**：

1. 不良率极低，长期 0.3% 级别
2. 所有不良几乎全部来自居民临时现金流波动（失业、疾病、短期困难），属于个体随机扰动
3. 几乎无实质性坏账损失
首付安全垫 + 住宅高流动性 + 国内全额追索制度
即便逾期、起诉、拍卖，银行基本无损

**和企业抵押的天壤之别**：

- 企业抵押不良：单笔直接亏 50%–100%
- 个人按揭不良：零星波动、几乎无损

**真实定性**：
房贷是中国银行业过去二十年、现在、未来，综合质量最高、最稳、最可持续的核心资产。

它唯一的变化：
不是质量变差，是新增优质标的变少、行业增量见顶。

**缺点**：

1. 新增规模逐年萎缩（需求下降，与质量无关）
2. 长期薄利化，净息差持续压缩

### 2. 信用卡业务

**抓手**：个人征信约束

**优点**：海量分散、单户小额、风险摊薄、规模化最强
**缺点**：仅靠征信单一软肋，收入断裂后约束失效

### 3. 纯信用消费贷

**抓手**：征信

**特点**：无抵押、无抓手、软肋最弱、风险最高

### 4. 商品场景分期（3C、家电、汽车分期）

**抓手**：场景绑定 + 征信

**特点**：商品快速贬值、无实质兜底，本质纯信用

### 5. 个人房产抵押消费贷

**抓手**：个人住宅抵押

**特点**：资产稳、损失极低，属于优质私贷品类

## 全文总结

1. 最差信贷结构：企业厂房土地抵押
顺周期虚高资产、悖论最强、出险必大亏、依托企业经营与人的风险。
2. 中等信贷结构：集团授信、普通小微、消费贷、信用卡、城投政信授信
高度依托主体经营、个人征信、声誉或政策博弈，约束条件存在外部变数。
3. 最优对公结构：保理 / 供应链应收
唯一彻底剥离个人道德风险、经营者风险、主观违约风险；风险下限锚定核心企业信用，贸易确权真实前提下，风险结构最干净。
4. 全行业最优总资产：个人住房按揭
几十年验证：低不良、几乎零损失、最稳现金流；唯一变化：增量萎缩，整体质量未降级，但需要持续关注客群杠杆与现金流缓冲带来的韧性边际变化。

最终四句终极定调（全文核心金句）

- 企业实物抵押：看着有抵押，实则最虚无，出险巨亏
- 保理供应链：不靠人、无道德风险、结构最干净
- 信用卡消费贷：靠征信、靠人性、风险分散但偏弱
- 个人住房按揭：中国银行体系永恒压舱石，质量始终最优

## 附：框架拓展 —— 软肋强度分级矩阵构想

> 可以作为后续写作升级方向，把全部信贷产品映射二维矩阵

- 横轴：约束机制刚性程度（从强到弱）：法律处置＞声誉成本＞持续经营资格＞征信记录＞道德自觉
- 纵轴：借款人违约爆发时刻，该约束机制是否依旧有效

每一类信贷产品，可以落在矩阵对应坐标，直观判断：什么场景之下，这套风控抓手会直接失效。
