# J51.三大平衡（一）：低成本内卷引发外循环失衡

从系统论视角来看，任何能够长期稳定运行的系统，都遵循同一个底层规律：系统内部产出的物质、能量、价值，输入与输出必须大体对等。倘若长期持续单向向外输送能量、输出价值，内部不断净流失资源，这套系统一定会持续损耗自身，平衡状态被打破，发展模式不具备可持续性。

如果把整个社会经济体比作一头奶牛，这个比喻能直观解释长期大额贸易顺差的内在矛盾。我们不断投入资源、人力、原料来喂养这头 “奶牛”，持续培育生产能力，可产出的大量商品、劳动价值，都如同牛乳一般持续对外输送。外界只看到源源不断向外供给的产出，夸赞产能充沛、外贸繁荣，却容易忽略核心问题：奶牛自身产出的养分长期单向外流，没能充分留在体内滋养自身。即便持续投喂养料，可挤取产出的速度远大于养分回流补充的速度，长此以往，机体的内在根基会不断被消耗。放到全球格局里看，长期依靠低成本劳动向外供给大量商品的发展模式，就如同持续挤奶的奶牛，本国创造的核心劳动价值大量对外输出，难以充分转化为本国居民的收入与民生福利，这正是内外两大循环失衡的底层根源。

所有市场经济的企业竞争，自始至终只有两条、且仅有两条底层生存路径。

第一条路径，是价值提升路径。

通过技术升级、工艺迭代、品牌溢价、产品创新、深加工增值，依靠提高商品的附加值获取市场利润。走这条路的企业，利润空间充足，不需要压榨劳动、不需要压低工资、不需要压缩从业者收益。产业越升级，劳动价值越高，劳动者收入越高，社会进入正向循环。

第二条路径，是成本压缩路径。

不靠创新、不靠技术、不靠价值增值，唯一的竞争手段就是压成本。而所有成本里，最好压、最见效、最无风险的，就是压缩劳动成本。压低工资、拉长工时、降低福利、压低上游农户和生产者收益，依靠极致低价换取市场竞争力。

资本天生逐利，天生短视。

创新周期长、投入大、风险高；压人力成本零成本、零风险、立刻见效。

于是就会形成全社会不可逆的路径依赖。

当一个社会的可贸易部门 —— 制造业、出口产业、农产品外销、代工生产、大宗商品出口 —— 普遍选择以 “压缩劳动成本” 作为核心竞争方式时，整个社会的经济逻辑会彻底被扭曲。

在这里，必须补充一个极其关键的时代判断：

出口退税、出口贸易补贴政策，在改革开放初期、产业空白阶段，是正确且必要的历史选择。

早年我们没有产业、没有市场、没有技术、没有海外渠道。

依靠出口补贴、出口退税，让利海外、低价换市场，快速建立工业体系、吸纳海量就业、完成原始资本积累。

在那个物资匮乏、产业弱小的年代，这套政策是助推中国工业化崛起的关键抓手。

但是，时代彻底变了。

在中国已经成为全球第一贸易大国、工业体系最全、贸易顺差常年万亿级的今天，长期高额货物贸易结余本身就是内外两大循环失衡的直观体现，而低成本内卷模式是催生这一失衡的核心诱因，出口退税与出口补贴，已经从历史功臣，变成了违背时代、加剧内卷、固化低端路径的机制。

这套政策现在起到的唯一核心作用：

用国家财政补贴企业低价内卷，强行续命低端产能，彻底锁死产业升级动力。

大量出口企业，本身没有技术溢价、没有品牌利润，完全靠退税补贴活着。

企业不需要创新、不需要提质、不需要抬高产品价值。

国家退税兜底，企业就敢无限降价、无限卷成本、无限压榨劳动。

政策 + 资本 双向合流，彻底把 “压缩劳动换低价” 变成了全社会不可撼动的路径依赖。

可贸易部门是一个国家劳动定价的 “价值锚”。

可贸易部门长期内卷、长期压劳动、长期低价竞争，再叠加出口退税的政策兜底，会直接压制全社会所有行业的劳动价值。

经济天然分为两大板块：可贸易部门与不可贸易部门。

可贸易的商品全球比价，靠着退税补贴 + 压劳动成本双重优势，疯狂低价抢占市场，持续压低工人、生产者、农户的劳动回报。

而不可贸易部门 —— 本地服务、维修、餐饮、家政、民生服务，完全跟随国内劳动定价体系。

这就出现了最真实、最扎心的现实：

同样的劳动、同样的工时、同样的技术，美国修空调 200 美元，中国修空调 200 人民币。

并不是我们的服务价值低，

是可贸易部门长期低成本内卷，叠加过时的出口补贴机制，把整个国家的社会劳动定价，死死按在了地板上。

可贸易部门的恶性路径依赖，会完成三层毒害传导：

第一，毒害产业本身

企业不靠创新赚钱，不靠价值赚钱，只靠政策补贴 + 压榨劳动赚钱。

永远没有动力升级技术、打造品牌、提高附加值，产业永久锁定在全球分工的最低端，永远无法高端突破。落后产能被政策续命，优质创新企业反而被低价内卷挤垮，形成劣币驱逐良币。

第二，毒害全社会劳动价值

制造业、农业、外贸的低工资，成为全社会劳动的基准线。

所有本地服务业、所有普通体力劳动、所有基层岗位，全部被锚定在低价值区间，全社会劳动集体贬值。

第三，毒害整个社会经济循环

全民劳动价值低→居民收入低→内需疲软→国内消费不足→只能更加依赖出口→国家继续退税补贴兜底→企业继续压劳动内卷。

至此，死循环彻底锁死。

长期高额顺差带来的内外循环失衡根源清晰：

不是行业竞争，不是市场激烈，

是政策兜底 + 资本逐短利，共同固化了 “压榨劳动换低价优势” 的全社会路径依赖。

曾经利国的出口补贴政策，在产能过剩、顺差巨大、产业成熟的当下，已经变成阻碍社会升值、阻碍劳动涨价、阻碍产业升级的时代桎梏。

只要这条路径不打破，产业不可能升级，劳动价值不可能上涨，分配问题不可能根本解决，内需不可能激活，普通人收入永远跑不赢时代。

因此，未来社会想要重塑内外循环平衡，核心要解决的问题只有一件：

强制抑制、打破、终结可贸易部门的低成本内卷路径依赖。

逐步退出过时的出口退税、低端贸易补贴体系，撤走低端内卷的政策兜底。

堵死资本最简单的 “压劳动套利” 捷径，

撤掉低端产能 “靠补贴苟活” 的政策温床，

逼企业从 “拼成本、拼压榨、拼低价”

转向 “拼技术、拼价值、拼创新、拼附加值”。

只有可贸易部门完成价值升级，

贸易收支回归合理区间、内外循环重新趋向平衡，

全社会的劳动定价才能抬升，

不可贸易的民生服务劳动才能回归真实价值，

普通人的劳动，才配得上真正的市场价格。

调整外贸端低成本内卷，修复外循环失衡，是全社会走向均衡高质量发展的关键一步。
