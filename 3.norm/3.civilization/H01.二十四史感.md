# H1.二十四史感

## 【二十四史感-自序】

壬寅岁，闭户读史。不稽典故，不考训诂，唯以一心，沉潜于兴亡起落之间。

久之，浩繁卷帙，如汤沃雪，唯余二十四象，历历在目。始知历史非故事，乃气运之波形；非他者之迹，乃自心之证。

五帝为源，清季为渊，百年浴火，方知今日之重。此二十四感，非敢曰知史，乃余沉淀后之史骨也。

后立 “五道一法”，推演世事，回头视之，其理暗合。方悟：史为体，理为用，沉淀为桥。

录此二十四感，以为 “五道一法” 史部之根。愿后来者，不只见文字，能见其后的静定与痛切。

—— 五道一法 创立者
