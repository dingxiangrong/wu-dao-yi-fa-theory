# 100 开篇总纲｜帝制演化三主线总叙 1.0

【正文】
西周原生封建之构，随礼崩而解体。秦始创大一统巨型单构，自此历史主线，不再是多构列国之间势能博弈，转为这一巨型帝国构的持续迭代、内部应力流转与代偿生长。
全程并行三条纠缠演化主线，同时序推进，互相牵引、互相制约：
其一，皇权集权演化线。势能持续向中枢收拢，不断拆分、重构中间层级子构，收束地方、官僚的自主力量，调整荷载边界，在收拢与过载之间反复取舍。
其二，去贵族平民化线。统治资格逐步剥离血统世袭特权，准入标尺持续改写，由世卿世禄，转向军功、察举、门第，最终定型于科举，权力通道向无世袭爵禄的读书人开放；平民化不等于均等化，只是废除血统天然垄断，代之以新的筛选门槛。
其三，宗族家族代偿线。旧贵族圈层消散之后，零散小民缺少稳定缓冲单元。宗族家族作为基层次级子构逐步成型，礼教下沉族内，承接律令难以覆盖的细碎矛盾，疏导基层应力；大族蓄积力量之后，又会形成反向张力，与中枢相互博弈。

集权收拢势能，平民化打碎旧血统壁垒，宗族化补上基层稳定缺口。三者同向生长，又互相制造新的应力。巨构内部应力，在朝廷、官僚、地方、宗族、民间之间流转转移，随时序累积，或疏导缓释，或锁闭内耗，直至应力突破阈值，旧构崩坏，新的迭代周期重启。
本辑沿用底层公理：构由力凝，应力恒存，唯有导、耗、转三途处置，别无他法；不再以列国对位为观测方式，转而观测单一巨型嵌套构的内部迭代、代偿与周期演化。

【点穴手评】
《华夏对位录》止于先秦列国博弈，以多构对峙为底色；本辑开启帝制时代，观测对象转为单一嵌套巨构。公理不变，观测范式切换：由对外对位，转为向内剖层。集权、平民化、宗族化三条主线，是帝制系统最核心的三条演化脉管，所有人事、制度、变法、动乱，都可挂靠在这三条脉管之上拆解勘验。

【百晓生评】
边界提示：三条主线不是匀速单向前进。集权有松有紧，平民化有反复反弹（如魏晋门阀），宗族有兴有抑。时序之中常有回潮、迂回、局部反向运动，不可简单理解为一路直线向前。三条主线互为代偿：中枢集权越强，越依赖宗族承担基层缓冲；贵族彻底消解，才给宗族铺开生长空间。
盲区提示：本辑聚焦汉至明清的帝制巨构，不脱离构力学公理；新的变量是嵌套层级激增、基层分布式子构（宗族）大规模常态化，应力转移路径远比先秦复杂。
