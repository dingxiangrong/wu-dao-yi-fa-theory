# 07 对位 - 礼制：周公与周平王｜隙存构稳，隙满则碎 1.0

【正文】
周公之时，分封格局依托荒野空余之地，各方单元之间留有缓冲余地，用来容纳内部的拉扯张力，这套富有弹性的秩序得以安稳运行；周平王东迁之后，空地尽数开垦瓜分，天然缓冲余地耗尽，各方势力紧贴对峙，弹性不复，力量刚性相撞，最终秩序瓦解。

任何一套制衡秩序，内部拉扯张力本就必然存在。弹性秩序的关键，就在于单元之间留有缓冲空间。这类余地很多并非人为刻意设计，而是客观地缘自带。留有空隙，张力才有疏导之处，这是弹性能够维持的根基。周初宗法分封之下，各个封国是独立单元，封国之间大量未开垦的荒地，便是天然缓冲地带。各方势力有向外开拓的出路，冲突向外释放，不必在边界、名分的约束上直接硬碰，积蓄的力量消耗平缓，格局长期稳定。

到西周末年、东周之初，人口增殖，列国不断开垦拓地。待到平王东迁，中原空余土地基本瓜分完毕，封国疆界彼此接壤，缓冲余地彻底耗尽。没有空间容纳张力，弹性的根基消失，各方力量再无回旋之地。原本向外疏导的矛盾，只能在交界之处直接对冲，持续消耗分封秩序积攒的势能，列国兼并、征伐纷争接连兴起。

二者对照，道理清晰：
周公建制承隙，凭余地以纳张力；
平王东迁隙满，失柔基而致序崩。

【诗评】
荒隙藏柔量，
牵冲自可容。
野封耕尽后，
相轧锁难重。

【引申对照】
企业组织同理。外部市场尚有柔性拓展空间，业务膨胀的势能向外释放，内部博弈应力自然舒缓。一旦市场见顶、外拓通道闭合，若各业务单元之间无缓冲缝隙，权责边界紧贴卡死，应力无处疏导，部门之间便陷入持续内耗，消耗组织势能。
稳定的组织，要么保有外部增长出口，要么在内部单元间预留缓冲空间。缝隙不能消弭博弈，只用来疏导应力。外拓穷尽、内部缓冲耗尽，再加顶层管控力量衰减，组织失稳溃散便会加速。

【点穴手评】 
张力不可根除，弹性依托间隙而生。间隙分两类：外部边界为柔性可拓展状态时，子构向外宣泄张力；外部拓展走到尽头，则依靠子构之间的内部缝隙容纳应力。间隙耗尽，单元紧贴对冲，力量刚性互撞，持续耗损势能，直至秩序溃散。间隙是秩序的弹性储备，会随着开发、挤压逐步消耗。

【百晓生评】
本篇承接前面内耗、势能损耗的脉络，点明柔性秩序的先决条件。间隙不是消解张力，只是提供向外疏导的通路。通路消失，张力转为内部刚性对抗。这套缓冲机制同样依附客观条件，间隙耗尽之后，单纯依靠旧有名分，无法承载蓄积起来的冲突。
